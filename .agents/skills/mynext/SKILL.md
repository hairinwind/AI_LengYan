# 生成下一个佛经学习文档 (MyNext)

用于按章节号自动检测序号并生成下一个空的学习模板文件。

## 参数与映射 (Arguments & Mapping)
用户输入阿拉伯数字章节号（例如 `8`, `9`, `10`），自动转换为中文数字：
- `8` $\rightarrow$ `八`
- `9` $\rightarrow$ `九`
- `10` $\rightarrow$ `十`
- `11` $\rightarrow$ `十一`
- `12` $\rightarrow$ `十二`

## 执行流程 (Workflow)
1. **定位章节目录**：根据用户提供的章节号定位目录 `<章节号>/`（如 `9/`）。
2. **扫描序号**：列出该目录下所有匹配 `楞严经-第*章-XXXX.md` 的文件，提取 4 位数字序号 `XXXX`。
3. **计算新序号**：
   - 若目录为空或无对应文件，初始序号设定为 `0010`。
   - 若目录存在文件，下一个序号为 $\max(\text{sequence}) + 10$（补齐 4 位数字，如 `0150`）。
4. **生成新文档**：在章节目录下创建新文件 `楞严经-第<汉字章节>章-<XXXX>.md`。
5. **写入基础模板**：
   ```markdown
   ## 经文
   ```
   ```

   ## 逐句白话译文

   ****


   ---
   ```
