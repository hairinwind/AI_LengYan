# 佛经学习文本格式化（Study Fojing）

## 功能说明

为佛经学习文档中的逐句白话译文自动添加格式化：
- 为每一句经文添加 `**` 标记（加粗）
- 用 `---` 分割符分隔各段落

## 何时使用

- 初始化新的佛经学习文档
- 为"逐句白话译文"部分填充经文段落
- 标准化已有文档的格式

## 使用步骤

1. 打开包含"经文"和"逐句白话译文"部分的 Markdown 文档
2. 输入 `/study_fojing` 或 `/myinit` 指令
3. 智能体将自动：
   - 提取"经文"部分的每一段
   - 在"逐句白话译文"部分为每段添加 `**text**` 格式
   - 用 `---` 分割各段落

## 格式要求

文档应包含以下结构：

```markdown
## 经文
\`\`\`
第一段经文。
第二段经文。
\`\`\`

## 逐句白话译文

*（在此处填充格式化的经文段落）*
```

## 示例

**输入** - 只有第一段：
```markdown
## 逐句白话译文

**阿难，是善男子尽是清净四十一心，次成四种妙圆加行。**

---
```

**输出** - 所有段落都格式化：
```markdown
## 逐句白话译文

**阿难，是善男子尽是清净四十一心，次成四种妙圆加行。**

---

**即以佛觉用为己心，若出未出，犹如钻火，欲然其木，名为暖地。**

---

**又以己心成佛所履，若依非依，如登高山，身入虚空，下有微碍，名为顶地。**

---
```
