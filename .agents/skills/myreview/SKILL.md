# 佛经译文审查规范 (MyReview)

用于审查佛经学习文档中“## 逐句白话译文”部分的准确性与教理严谨性。

## 核心审查原则 (Core Principles)

1. **仅纠正本质理解错误 (Substantive Misunderstandings Only)**：
   - 严格区分“义理/教理理解错误”与“字面行文风格差异”。
   - 凡不影响经文原意、仅为个人遣词造句或表达习惯不同的，一律不予指出。

2. **结论前双重自查 (Pre-conclusion Verification)**：
   - 在给出修改意见前，必须反复核查所拟指出的问题是否与原作者解释存在真正的本质分歧，排除字面表象差异的干扰。

3. **正确的无需赘述 (No Redundant Elaboration If Correct)**：
   - 若全篇译文不存在本质错误，**严禁逐句罗列或展开分析**，直接输出简明结论（例如：“经复核，全篇译文对义理的理解完全准确，无本质理解错误。”）。

4. **错误报告规范 (Error Reporting Format)**：
   - 仅在发现确凿的本质错误时，才精准定位段落，按如下规范输出：
     - **【原经文】**：对应经文句段
     - **【当前译文】**：用户撰写的白话解释
     - **【本质分歧】**：指明具体偏差何在，为何属于本质错误
     - **【注疏依据】**：引用权威经典注疏（如《正脉疏》、《讲义》等）作为佐证

## 执行流程 (Workflow)

1. **定位目标文件**：获取用户指定路径的文档；若未提供参数，则默认获取当前正在编辑的活动文档。
2. **提取对照文本**：提取文档中的“## 经文”代码块与“## 逐句白话译文”中各分段解释。
3. **义理核验**：结合经典原义与权威注疏逐条比对。
4. **自查与裁决**：
   - 若无本质错误 $\rightarrow$ 输出简明肯定结论，结束流程。
   - 若有本质错误 $\rightarrow$ 按规范格式精准指出错误项与依据。
