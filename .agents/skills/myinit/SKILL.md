# 佛经学习文本初始化 (MyInit)

用于在佛经学习文档中自动填充并格式化经文段落至“逐句白话译文”区域。

## 目标 (Objective)
在当前打开的 Markdown 文件中，为“## 逐句白话译文”部分自动填充和格式化经文段落。

## 操作规则 (Execution Rules)
1. **提取经文**：从 `## 经文` 部分下的代码块中提取所有段落。
2. **格式化**：对每一段经文：
   - 两侧添加 `**` 标记（粗体）。
   - 段落之间使用 `---` 分割线。
3. **保持结构**：不修改文件的其他已有译文或说明部分。

## 具体执行流程 (Workflow)
1. 读取目标 Markdown 文件（如当前打开的章节文档）。
2. 解析 `## 经文` 代码块中的每一非空段落。
3. 检查 `## 逐句白话译文` 部分。
4. 将经文段落按如下模板组织并写入文件：
   ```markdown
   **<经文段落内容>**

   ---
   ```
5. 保存并更新文件。
